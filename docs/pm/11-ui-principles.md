# 11 界面与交互原则（2026-11-15 定）

从客户（CX）和产品（PM）两个角度统一整个网站。新页面、新功能都按这里来。

| 原则 | 规则 | 为什么 |
|---|---|---|
| **导航顺序一致** | logo、日历、行程、狗狗、好友，然后是设置、头像。桌面端是左侧竖栏（设置和头像在最下），手机端是顶栏（设置和头像在最右） | 换设备不用重新找；常用的在前，低频的在后 |
| **页面宽度一致** | 列表和表单页（行程、狗狗、好友、设置、个人主页）都是居中的窄栏；只有日历和行程详情这类需要空间的页面用宽版 | 手机横屏和平板上不出现一整行拉得很长的表单 |
| **返回按钮一致** | 圆形、带细边的 ‹ 按钮，在标题栏最左；不再用文字链接 | 和日历翻页、铅笔等圆形按钮是同一套控件，不再"格格不入" |
| **先看后改** | 个人主页、狗狗档案默认只读：头像、名字、小习惯、兴趣、饮食都只是展示；点铅笔才进入编辑，底部有"保存修改 / 放弃修改" | 防止滑动页面时误改；一眼看清信息，需要时才改 |
| **一个信息一个家** | 狗狗只在"狗狗"里管理，个人主页不再重复列出狗狗；好友只在"我的好友"里管理 | 重复入口会让人不知道改哪边 |
| **名字统一** | 一律叫"好友"（不再用"朋友""伙伴"） | 同一个东西同一个叫法 |
| **不写说明文字** | 除了错误、确认和用户要求的提示，界面上不放解释性小字 | 保持干净；危险操作靠点击后的确认弹窗 |
| **图标一致** | 全部用同一套贴纸图标；兴趣和"想法"的类别用同一份名称和图标 | 品牌一致，也少一套要维护的东西 |
