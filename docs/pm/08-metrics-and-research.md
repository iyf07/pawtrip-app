# 08 指标与用户研究

## 北极星指标（每个产品一个）

| 产品 | 北极星指标 | 为什么 |
|---|---|---|
| **Paw Trip** | **每周“被确认的计划条目”数（至少 2 位成员参与的行程）** | 代表真正的协作和计划完成，而不是只注册 |
| **Paw Care/Track** | **每周至少记录一次的家庭数** | 日常习惯 |
| **Paw Places** | **每周被加入计划或被收藏的地点数** | 发现带来价值 |
| **Paw Feel** | **分享出去的情绪卡片数**（如果做） | 好玩与传播 |

## Paw Trip 的漏斗（先建立基线，再设目标）

```
访问 → 注册（收到验证码并登录）→ 建立行程 → 邀请 ≥ 1 位成员 → 成员加入 → 添加 ≥ 3 个条目 → 确认 ≥ 1 个条目 → 旅行期间回访 → 旅行后回访
```

| 阶段 | 指标 | 目标（初始假设，上线后校准） |
|---|---|---|
| 激活 | 注册后 24 小时内建立行程且邀请 ≥ 1 人的比例 | ≥ 30% |
| 邀请转化 | 被邀请者加入的比例 | ≥ 50% |
| 协作 | 有 ≥ 2 位成员活跃的行程比例 | ≥ 40% |
| 留存（事件驱动） | 行程出发日前后 7 天内回访的比例 | ≥ 60% |
| 质量 | 崩溃率、页面加载时间 | 崩溃率 < 1% |
| 满意 | 反馈中正面比例、应用评分 | ≥ 4.5 |

**行业留存参考**（口径不同，只当方向）：不同来源给出的 App 平均 D1 约 25–28%、D7 约 6–18%、D30 约 3–8%（[GetStream 汇总](https://getstream.io/blog/app-retention-guide)）。旅行/生活方式类天然更低，因为人们一年只出门几次，应该用“**围绕旅行事件**的回访”来衡量，而不是每日活跃。

## 需要埋点的核心事件（T05）

`sign_up`、`login`、`trip_created`、`member_invited`、`member_joined`、`item_created`（带类别）、`item_confirmed`、`item_dragged`、`dog_added`、`photo_uploaded`、`feedback_submitted`、`share_clicked`、`invite_opened`、`account_deleted`。
- 隐私：不记录邮箱、不记录文本内容；用匿名用户 ID。

## 持续发现：每周怎么和客户在一起

- **每周 3–5 次接触**：访谈、看用户使用录屏（经同意）、读反馈、观察内测用户。
- **每次访谈 30 分钟**：只问**过去的真实行为**，不问“你会不会用”。
- 访谈要找**目标用户**：爱带狗出行的朋友圈（首要）、多狗家庭（Care）。

### 访谈提纲（旅行）

1. 讲讲**上一次**带狗出去过夜的旅行：怎么决定去哪？谁参与？
2. 订住宿时你做了什么？**最麻烦的一步**是什么？花了多久？
3. 你们怎么在群里讨论行程？有哪些东西最容易乱？
4. 狗狗不能去的地方，你们怎么安排？
5. 出发前你会检查/准备什么？有过**忘带**的东西吗？
6. 你现在用什么工具规划？它**不好用**的地方？
7. （给他们看原型）请你试着建一个周末行程，说出你的想法。

### 访谈提纲（Care）

1. 家里有几只狗？谁负责喂、遛、带去看病？
2. 疫苗、体重、看诊记录现在放在哪里？上次找记录是什么时候？
3. 换兽医或寄养时，你需要提供什么信息？怎么准备？
4. 有没有漏过**疫苗/药/体检**？当时发生了什么？
5. 你愿意为什么**付费**？为什么？

## 假设清单（要验证，不要当事实）

| # | 假设 | 验证方式 | 状态 |
|---|---|---|---|
| H1 | 带狗旅行里最痛的是**住宿信息**，不是景点 | 访谈 + 内测中看哪类条目最常被添加 | 待验证 |
| H2 | 朋友愿意为了一次旅行装 App，只要邀请链接顺畅 | 看邀请 → 加入转化 | 待验证 |
| H3 | 多狗家庭的主要价值在**提醒**而非记录 | Care 访谈 + 功能使用数据 | 待验证 |
| H4 | 用户愿意为“离线 + 狗狗清单 + 回忆”付费 | 访谈 + 价格实验 | 待验证 |
| H5 | 狗狗情绪分析，用户更在乎好玩而非准确 | Feel 小原型测试 | 待验证 |

## 反馈与数据怎么变成决定

1. 反馈和访谈 → 写成“**客户原话 + 场景**”，贴到需求池对应条目的证据里。
2. 同一个痛点出现 **3 次**，提升优先级；出现 **1 次**，只记录。
3. 数据显示漏斗中某一步掉得很多，先**访谈**为什么，再决定怎么改。
4. 每个月做一次“**我们学到了什么**”小结，更新假设状态。
