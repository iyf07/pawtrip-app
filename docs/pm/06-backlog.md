# 需求池（Backlog）

> 这份清单尽量完整，但**所有分数都是初步估计**，需要用真实用户访谈和上线后的数据来校正。按 RICE 排序，Kano 说明这个功能对用户是“基本期待 / 性能型 / 惊喜型”，MoSCoW 决定这一阶段做不做。
>
> **RICE = 覆盖面（R，受影响用户占比 %）× 影响力（I，3 极大、2 大、1 中、0.5 小、0.25 极小）× 信心（C）÷ 工作量（E，人周，按“你 + AI 助手”估算）。**
