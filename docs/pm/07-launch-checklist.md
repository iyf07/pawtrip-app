# 07 上线清单（网页 + iOS）

> 勾选后更新。来源：[Apple：应用内删除账号](https://developer.apple.com/support/offering-account-deletion-in-your-app)、[Apple 审核指南 5.1.1](https://developer.apple.com/help/app-review/guideline-reference/5-1-1-account-deletion)、[Adjust：软发布策略](https://www.adjust.com/blog/soft-launch-strategies-to-boost-user-acquisition/)。**苹果政策会变化，提交前请到官方页面再核对一遍。**

## A. 发布阶段（逐步放量）

```
自己用 → 内测（TestFlight，邀请制，10–30 人）→ 软发布（小范围公开）→ 分阶段发布（1% → 5% → 25% → 100%）→ 正式上线
```
- TestFlight 外部测试最多支持约 1 万人，测试者可以直接截图反馈（以苹果当前文档为准）。
- 每个阶段都有退出标准（见 `05-roadmap.md`），不达标不放量。

## B. 基础设施（网页与后端）

- [ ] 买根域名，DNS 放在 Cloudflare（免费）。
- [ ] 每个产品一个子域名（`trip.根域名` 等），接 EAS 自定义域名（付费功能，一个项目一个域名）。
- [ ] 发信：Resend 验证根域名，Supabase 配置 SMTP，推送带 6 位验证码的邮件模板。
- [ ] Supabase 重定向地址和站点地址更新为正式域名。
- [ ] 预发布（staging）环境：独立 Supabase 项目与环境变量。
- [ ] 自动备份已开启，**做过一次恢复演练**。
- [ ] 错误监控（网页 + iOS），告警发到邮箱。
- [ ] 产品分析（核心事件与漏斗）。
- [ ] CI：提交时自动类型检查、lint、数据库测试。
- [ ] 限流与防滥用（邀请码、反馈、登录）。
- [ ] 费用告警（Supabase、Mapbox、EAS）。

## C. 法务与合规

- [ ] 隐私政策（说明收集什么、怎么用、是否共享、保留与删除）。
- [ ] 服务条款。
- [ ] 支持页面与联系邮箱。
- [ ] **应用内可访问隐私政策**，并在 App Store Connect 里填写网址（审核要求，以苹果现行指南为准）。
- [ ] **应用内删除账号**并清除关联数据与图片（苹果 5.1.1(v)；仅“停用”不够）。
- [ ] 如果提供第三方登录（如 Google），**必须同时提供 Sign in with Apple**，并在删除账号时撤销令牌。
- [ ] 数据导出（用户数据权利）。
- [ ] 商标与名称检查（USPTO、App Store、Google Play）。
- [ ] 第三方服务条款核对：Mapbox、Open-Meteo（天气接口）、字体、图标的许可。
- [ ] 儿童相关：确认不面向 13 岁以下；填写年龄分级。

## D. iOS 提交（App Store Connect）

- [ ] Apple 开发者账号（$99/年）。
- [ ] **Bundle ID 已确定**（上架后不能改）。
- [ ] 应用名称、副标题、关键词、描述（简体中文 + 英文）。
- [ ] 应用图标（1024）、启动页。
- [ ] 截图（各设备尺寸）与可选的预览视频。
- [ ] **隐私营养标签**（数据类型：联系信息、用户内容、位置如果有、使用数据、诊断）。
- [ ] **权限说明文字**：相机、相册、定位（如使用）要写清楚“为什么需要”。
- [ ] 审核备注：提供一个**测试账号**和说明（邮箱验证码登录很难审核，要给审核员一个能直接用的方法，例如固定验证码的测试账号）。
- [ ] 支持网址、营销网址、隐私政策网址。
- [ ] 年龄分级问卷。
- [ ] 版本说明（What's New）。
- [ ] 崩溃率和启动时间在可接受范围。
- [ ] 在真机（不同尺寸 iPhone）上走完全部关键流程。

## E. 产品体验检查

- [ ] 手机、平板、电脑宽度都检查（网页）。
- [ ] 深色与浅色模式。
- [ ] 简体中文与英文文案。
- [ ] 无网络、慢网络时的表现（至少有明确的错误提示和重试）。
- [ ] 空状态、错误状态、加载状态都有设计。
- [ ] 无障碍：读屏标签、对比度、可点击区域。
- [ ] 新用户首次使用流程（引导）从头走一遍。
- [ ] 邀请链接：电脑、手机、未安装 App 三种场景都能走通。

## F. 增长与运营

- [ ] 内测招募渠道（狗主人社区、本地遛狗群、朋友圈）。
- [ ] 等待名单页面。
- [ ] 品牌首页（根域名）。
- [ ] 客服邮箱与常见问题。
- [ ] 反馈处理流程（每周处理 + 回写状态）。
- [ ] 发布公告与社交内容。

## G. 上线当周的值守

- [ ] 每天看错误监控、反馈、评分。
- [ ] 有严重问题的回滚办法（上一个版本、功能开关）。
- [ ] 一周后复盘：对照目标指标，决定放量、改进还是暂停。
